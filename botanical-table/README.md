# ボタニカル表｜Bar Soutsu

ジンに使われる代表的なボタニカルと香気成分を検索・比較する社内ツール。

## できること

- ボタニカル名・香気成分・香りの説明で検索
- 分類・植物の科ごとの絞り込み
- 名前・科名・分類・部位・成分数で並び替え
- 複数ボタニカルを選択して、香気成分を横断集計
- 香気成分表を重なり順・成分名順・系統順で並び替え

## データ

- `botanical-data.js` は、ボタニカル表・ジン在庫カタログ・蒸留ノートが共通で読み込むデータ。ボタニカルを足すときは、このファイルだけ直す。
- 分類（group）は14種類（骨格・樹脂、シード・スパイス、根・土台、シトラス、和ボタニカル、樹皮・ウッディ、ハーブ・グリーン、花・フローラル、海・ミネラル、果実・野菜、ナッツ・焙煎、甘味・樽香、茶・ドライ、果実・ベリー）のどれかにする。
- `aliasMap` は、在庫カタログの表記ゆれ（例：生姜）を表の名前（例：ジンジャー）に読み替える辞書。検索でも使う。
- 在庫カタログでよく使われる99種には `literature`（文献データ）がある。論文・公的資料から集めた精油の量（`oil`：%・文献の幅・試料と蒸留法・出典）、精油の成分の割合（`composition`）、出典（`sources`）、注意書き（`note`）。果実・茶・バニラは精油がほとんどないので、香気成分（バニラはバニリン）の総量を入れ、`oil.label` に何の量かを書く。蒸留ノートは、この値で香りの構成を計算する。
- 成分（`components`）の一部には、水に溶かしたときの閾値（`threshold`、µg/L）と出典がある。文献による差が大きい参考値。

## 注意

香気成分は代表例です。品種・産地・乾燥状態・抽出方法・蒸留時のカット位置で実際の香りは変わります。
