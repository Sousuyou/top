一杯の提供設計

味と口当たりの目標を決めてから、仕込み方、混ぜ方、グラス、提供方法を選びます。新しい技法を取り入れるときの、考え方の整理です。

  • 新しいカクテルを考えるとき

最初の一口と、飲み終わりを一緒に考える

新しい技法を使うと、できた直後の香りや見た目に意識が集中します。しかしお客様は、会話をしながら時間をかけて飲みます。氷が溶け、温度が上がり、泡が落ち着いたときにも楽しめるかまで含めて、一杯を完成させます。

開発では、提供直後だけでなく、少し時間を置いてもう一度飲みます。変化が大きければ、配合、量、グラス、提供氷を見直します。この確認によって、どの技法を残すべきかも判断しやすくなります。

仕組みと考え方

温度と加水によって味の感じ方は変わるため、提供時の一点だけに合わせたバランスは、その後に崩れることがあります。飲み方と経過時間を含めて評価することが、技法を営業の一杯へつなぐ考え方です。

参考：Erik Lorincz: Kwant (London)

一杯への取り入れ方

完成直後と数分後の両方で好ましいかを確認します。技法の数ではなく、飲み終わるまでの体験を基準に採用します。

ほかのバーテンダーの考え方

Simone Caporale — 経歴と視点を読む →

2019年の取材で、味の感じ方には記憶や気分、周囲の環境も関わると語っています。香りを閉じ込めた食用の泡のように、口をつける前の体験から一杯を組み立てる実践が特徴的です。

参考：Simone Caporale — 2019年インタビュー

Ryan Chetiyawardana — 経歴と視点を読む →

White Lyanでは、あらかじめ作ったカクテルや独自の材料を使い、廃棄の少ない提供を試みました。完成時の味と提供の仕組みを先に考えると、注文のたびに行う工程と、仕込みで済ませる工程を選び直せます。

参考：Ryan Chetiyawardana — Mr Lyan公式紹介

上野秀嗣 — 経歴と視点を読む →

2011年の取材では、ハードシェイクを単に強く振る動作として捉えず、空気を含ませた軽い飲み口を目指す技術として説明しています。また、ダイヤモンド形の氷では、グラスの中で光が反射する見え方を重視しています。

参考：上野秀嗣 — 2011年インタビュー

Agostino Perrone — 経歴と視点を読む →

取材で繰り返し語るのは、客の希望をよく聞くことと、チームで一杯を作ること。整ったグラス、氷、ガーニッシュ、質感まで含めて提供を考えます。マティーニのような少ない材料の一杯ほど、調製と接客の細部が表れます。

参考：Agostino Perrone — Connaughtでの仕事 / Agostino Perrone — 2022年インタビュー

鹿山博康 — 経歴と視点を読む →

鹿山博康のCrystal Negroniでは、蒸留やミルクウォッシュで加工したカンパリを使い、飲み進めたときの味と見た目の変化を作っています。

参考：鹿山博康インタビュー — CAMPARI JAPAN

毛利隆雄 — 経歴と視点を読む →

毛利隆雄の公開レシピには、冷蔵したジンを100回ステアする手順と、事前に合わせて冷凍した場合の別手順があります。回数だけでなく、酒の初期温度と配合を含めて読むことが大切です。

参考：毛利隆雄のマティーニ — きょうの料理（2014） / 毛利隆雄インタビュー — 大人未来

Alessandro Palazzi — 経歴と視点を読む →

PalazziのDukes式は、冷凍庫で冷やしたジンとグラスを使うマティーニです。氷でステアする作り方とは加水の条件が異なり、目標の濃さも含めて比較します。

参考：Alessandro Palazzi — マティーニの考え方（2021） / Alessandro Palazzi — Sacred Spiritsインタビュー

Angus Winchester — 経歴と視点を読む →

Winchesterは、マティーニを作る前にジン、混ぜ方、ベルモットの量、ガーニッシュを確認するよう勧めています。好みを聞く工程が、技法の選択につながります。

参考：Angus Winchester — Food GPSインタビュー（2012） / Angus Winchester — Behind the bar（2017）

Simon Ford — 経歴と視点を読む →

Fordは、クラシックカクテルとボタニカルの組み合わせを整理してジンを開発しました。原液だけでなく、完成したカクテルでの働きから銘柄を選ぶ視点です。

参考：Simon Ford — ジン開発のフレーバーマップ（2016）

基本の手順

  1. どんな香り、味、口当たりにしたいかを決めます。
  2. その仕上がりに必要な材料と仕込み方を選びます。
  3. シェイクやステアなど、混ぜ方を決めます。
  4. グラスと提供方法を決め、実際に飲んで確かめます。

仕上げのポイント

  • お客様には、使った技法の説明に加えて、どんな味を楽しめる一杯なのかを伝えます。
  • 工程を追加する前に、その工程で何をよくしたいのかを明確にします。
