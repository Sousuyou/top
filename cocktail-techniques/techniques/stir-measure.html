計量とステア

材料を正確に量り、氷と一緒にかき混ぜて冷やす方法です。マティーニなどを毎回同じ味に仕上げるには、計量と、氷が溶けて加わる水の量をそろえることが大切です。

Erik Lorincz本人が重視する操作

向いているカクテル・用途

  • マティーニやマンハッタン
  • 毎回の仕上がりをそろえたい定番カクテル
基本の手順へ ↓参考資料へ ↓

秒数を覚える前に、完成した味を覚える

ステアは、透明でなめらかな一杯を作る基本です。練習ではスプーンの動きに目が向きますが、営業でそろえたいのは、材料の量、冷たさ、薄まり方です。動作が滑らかでも、仕上がりが毎回違えば、調整すべき点が残ります。

同じマティーニでも、氷、容器、材料温度が変わると、以前と同じ秒数がそのまま使えるとは限りません。最初に好ましい完成状態を作り、その状態へ安定して到達する手順を決めると、秒数が役に立ちます。

仕組みと考え方

加水はアルコール度数だけでなく、甘味、酸味、苦味の感じ方にも関わります。Arnoldらの試飲では、すべてに共通する理想の加水率は得られませんでした。完成する温度で味を決めることが、実務上の大切な点です。

バーテンダーの視点 · 要旨

Erik Lorincz

計量や道具の操作を丁寧に扱う姿勢は、派手な技法以外にも表れています。一杯を安定して仕上げる基礎として、こうした操作に注目できます。

資料の内容を要約し、本ガイドの解説を添えています。

一杯への取り入れ方

マティーニやマンハッタンは、一度に一つの条件を変えて比較します。氷と配合と時間を同時に変えない方が、狙った味へ近づけます。

ほかのバーテンダーの考え方

Agostino Perrone — 経歴と視点を読む →

取材で繰り返し語るのは、客の希望をよく聞くことと、チームで一杯を作ること。整ったグラス、氷、ガーニッシュ、質感まで含めて提供を考えます。マティーニのような少ない材料の一杯ほど、調製と接客の細部が表れます。

参考：Agostino Perrone — Connaughtでの仕事 / Agostino Perrone — 2022年インタビュー

毛利隆雄 — 経歴と視点を読む →

毛利隆雄の公開レシピには、冷蔵したジンを100回ステアする手順と、事前に合わせて冷凍した場合の別手順があります。回数だけでなく、酒の初期温度と配合を含めて読むことが大切です。

参考：毛利隆雄のマティーニ — きょうの料理（2014） / 毛利隆雄インタビュー — 大人未来

Alessandro Palazzi — 経歴と視点を読む →

PalazziのDukes式は、冷凍庫で冷やしたジンとグラスを使うマティーニです。氷でステアする作り方とは加水の条件が異なり、目標の濃さも含めて比較します。

参考：Alessandro Palazzi — マティーニの考え方（2021） / Alessandro Palazzi — Sacred Spiritsインタビュー

Angus Winchester — 経歴と視点を読む →

Winchesterは、マティーニを作る前にジン、混ぜ方、ベルモットの量、ガーニッシュを確認するよう勧めています。好みを聞く工程が、技法の選択につながります。

参考：Angus Winchester — Food GPSインタビュー（2012） / Angus Winchester — Behind the bar（2017）

Simon Ford — 経歴と視点を読む →

Fordは、クラシックカクテルとボタニカルの組み合わせを整理してジンを開発しました。原液だけでなく、完成したカクテルでの働きから銘柄を選ぶ視点です。

参考：Simon Ford — ジン開発のフレーバーマップ（2016）

基本の手順

  1. 目盛りに合わせて材料を量ります。
  2. 材料をこぼさず容器に移し、氷を加えます。
  3. バースプーンで、氷と液体を滑らかに動かします。
  4. 温度と薄まり方を確認し、グラスに注ぎます。

仕上げのポイント

  • 材料の量に加え、氷の状態と仕上がりもそろえます。
  • 器具を替えたときは、同じ秒数で同じ仕上がりになるか確認します。
使用上の注意・資料の補足
  • 静かに回せていることだけでは、十分に冷えたか、適度に薄まったかは判断できません。
  • 器具の紹介に書かれた性能は、第三者による比較実験の結果とは区別して読みます。
