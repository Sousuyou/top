# カクテル技法ガイド

Bar Soutsu Tools本体の `cocktail-techniques/` に組み込んだ閲覧モジュールです。トップのカード、共通メニュー、横断検索から開けます。ガイド上部のブランドリンクで本体トップへ戻ります。

## 編集

本文の編集元はこのディレクトリの `編集済みコンテンツ.json` です。画面構成は `build.py`、操作は `app.js`、外観は `styles.css` で編集します。

```
python3 cocktail-techniques/build.py
```

`top` ディレクトリで実行すると、HTMLとdata.jsonを再生成し、親ディレクトリのtheme.cssを複製します。以後の更新はこの組み込み版を編集してください。outputs内の検討版から自動同期はしません。

## 本体との接続

- `index.html` のカード、`nav.js` の共通リンク、`search.js` のツール検索に入口を追加。
- `integration.js` は本体のService Workerを登録。独立したService Workerは設けません。
- 本体の `service-worker.js` はガイド本文・CSS・JS・データを事前保存。内容更新時には本体のキャッシュ番号も更新してください。
- ガイドの4つの切り替えと関連資料のプレビューは、検討版と同じ操作です。

## 確認

ローカルブラウザでトップからガイドへの遷移と表示を確認。HTML・内部リンク・必要ファイルを検査し、JavaScriptの構文を確認済みです。Service Workerは模擬オフラインのテストで、検索URLから本文へ戻る処理と他ツールのキャッシュを保持する処理を確認しました。実機PWAのオフライン動作と公開先は別途確認が必要です。

本変更はローカルの組み込みです。GitHub Pagesへの公開には、このtopリポジトリの変更を通常の公開手順で反映します。
