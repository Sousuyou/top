ウェットシェイク材料を氷と一緒に振り、混ぜながら冷やす方法です。氷が溶けて適度に薄まり、空気を含むことで口当たりも変わります。

ダイキリや、フレッシュライムを使うギムレット / 卵白を使わないサイドカーやマルガリータ

作り方

  1. 材料を量り、シェーカーに入れます。
  2. 氷を加え、蓋をしっかり閉めます。
  3. 一定のリズムで、十分に勢いをつけて振ります。
  4. ストレーナーで氷を取り除き、グラスに注ぎます。
  • 一般的な柑橘系カクテルでは、まず10〜15秒を目安に振り、温度と薄まり方を確認します。
  • シェーカーは、作る量に合い、安定して振れるものを選びます。

Arnoldの冷却実験では、氷の量が十分で、氷が大量の表面水を持たず、よく振ることが前提です。氷が溶けるときに液体から熱を奪うため、冷却と加水は結びつきます。冷凍庫から出した低温の氷は、融け始める前にも熱を吸収するので、氷の初期温度までそろえることが比較の基本になります。

Arnoldは温度と加水を測り、上田氏は３ピースの使い方を重視しています。測定で管理する部分と、器具を使いこなして仕上げる部分の両方を学べます。

ダイキリを作るときは、ラム、ライム、砂糖を均一に混ぜるだけでなく、飲みやすい温度と濃さ、軽い口当たりを同時に作っています。この三つを分けて見ると、「もっと振るべきか」「配合を変えるべきか」が判断しやすくなります。

たとえば、十分に冷えているのに甘さが重い場合は、振る時間だけを延ばすより、甘味料や加水量を見直す方が調整しやすくなります。反対に、味のバランスはよいのに口当たりが平板なら、氷の構成や振り方、濾し方を比べる意味があります。

最初の基準は、使い慣れた器具で十分に勢いよく振ることです。冷たさと味が整ったら、次に泡や氷片の残り方を調整します。

ドライシェイク卵白などを含む材料を、まず氷なしで振って泡立て、その後に氷を加えて冷やす方法です。泡と液体が一緒に口へ入る、クリーミーな仕上がりを目指します。

卵白入りのウイスキーサワー / ピンクレディやアマレットサワー

作り方

  1. 材料を入れ、氷を加えずに振って泡立てます。
  2. 氷を加えて、もう一度振ります。
  3. 氷を取り除き、グラスに注ぎます。
  • 泡の高さだけでなく、液体と一緒に飲んだときのなめらかさを確認します。
  • 途中で蓋を開けて氷を足すため、開閉しやすく、十分な容量のあるシェーカーが便利です。

氷なしの工程ではまず泡を作り、氷ありの工程では冷却と加水を進めます。二つの工程を分けることで、それぞれの状態を確認できます。通常ドライとリバースの作り比べでは、泡の厚さと飲み物としてのまとまりが別々に評価されています。

アマレットサワーでは、氷なしで泡立ててから氷と振る順序を採用し、泡立てにはハンドブレンダーも使っています。手で振ることに限定せず、提供する一杯を安定させる方法として読めます。

卵白系のサワーは、表面の泡だけを食べる飲み物ではありません。グラスを傾けたとき、泡の下から酸味と酒の風味が自然に入ってくるかが大切です。通常のドライシェイクは、この一体感を目指す際のわかりやすい出発点になります。

泡が立っていても、上だけが重く、液体が後から流れ込むなら、泡の量を増やすことが解決にはなりません。卵白の量や、氷を入れた後の仕上げまで含めて調整します。

ウイスキーサワーなら、まず通常ドライで一杯を完成させ、飲み心地の基準を作ります。そこからリバースと比べると、泡の違いを選びやすくなります。

リバースドライ先に氷と一緒に振って冷やし、氷を取り除いてから、もう一度振って泡立てる方法です。表面に厚くしっかりした泡を作りたいときに検討します。

泡の層を目立たせたい卵白入りサワー / 高さのある泡を作りたいラモス・ジン・フィズのアレンジ

作り方

  1. 材料を氷と一緒に振って冷やします。
  2. ストレーナーを使い、氷を取り除きます。
  3. 氷なしでもう一度振って泡立て、グラスに注ぎます。
  • 通常のドライシェイクと作り比べ、泡の厚さと飲みやすさを確認します。
  • 見た目に厚い泡が欲しい場合と、泡が液体になじんだ口当たりが欲しい場合で使い分けます。

比較記事では、リバースに強い泡が見られた例があります。ただし卵白を後から加える方法も含まれます。試す際は、卵白を加える時点までレシピに書くと、同じ「リバース」という名前による手順の混同を防げます。

Morgenthalerのラモスは、クリームを入れる前に泡立てる構成です。リバースとは別に、材料を加える順番から泡を調整する方法もあります。

リバースドライの魅力は、最後の工程で泡を作り、その状態をグラスへ移せることです。泡の輪郭がはっきりすると、見た目にも、唇が触れた瞬間にも特徴が出ます。泡自体を一杯の主題にしたいときに使いどころがあります。

一方、厚い泡は液体との境目を感じさせることもあります。グラスの形と注ぐ量まで合わせて考え、最初の一口で泡と液体がどう入ってくるかを確かめます。

泡を目立たせるならリバース、液体とのなじみを優先するなら通常ドライ、という順で試すと違いをつかみやすくなります。

大きな氷の使い分けシェイクに使う氷の大きさを変え、泡立ちや口当たりを調整する方法です。大きな氷を使うと泡が増えた、という実務家の報告があります。

シェイクしたカクテルの泡立ちを変えたいとき / いつもの一杯を、より軽い口当たりに仕上げたいとき

作り方

  1. シェーカーの中で十分に動く大きさの氷を選びます。
  2. 必要に応じて小さい氷を加え、シェイクします。
  3. 泡立ち、口当たり、薄まり方をそれぞれ確認します。
  • 大きな氷と小さい氷を組み合わせる使い方が紹介されています。
  • 小型の３ピースでは、氷が大きすぎて動きを妨げないようにします。

大きな氷による泡量の増加は、Arnoldが観察として報告しています。その原因を一つに断定するより、食感を変える実用的な選択肢として使うのが適切です。冷却、加水、泡立ちを別々に評価すれば、その器具に合った氷の構成を探せます。

大きな氷だけでなく、小さい氷を組み合わせる使い方を紹介しています。氷のサイズを一種類に固定せず、食感と加水を一緒に調整する発想です。

氷の役割を冷却だけで考えると、大きい氷は「溶けにくいもの」という説明で終わってしまいます。しかしシェイクでは、泡立ちや液体の動きにも目を向けると、氷の選び方が広がります。

試すときは、いつもの氷と、大きな氷を含む組み合わせを、同じ材料量で比べます。泡が増えても薄まり方が好みから外れたなら、小さい氷の量などを調整して両方を整えます。

容量に余裕のある２ピースは比較を始めやすい器具です。小型３ピースでは、氷の大きさより、内部で十分に動けることを優先します。

濾し方の使い分けグラスに注ぐときに氷片や果肉を取り除き、口当たりを整える工程です。細かい粒を減らしたい場合は、目の細かいストレーナーを重ねて使います。

細かな氷片を残さず、なめらかに仕上げたいとき / 果肉の量を調整したいとき

作り方

  1. ストレーナーで大きな氷を押さえながら注ぎます。
  2. 細かな氷片や果肉も取り除く場合は、目の細かいストレーナーを通します。
  3. 飲んだときに、狙った口当たりになっているか確認します。
  • 二つのストレーナーを使って濾す方法を、ダブルストレインと呼びます。
  • シェーカーを比較するときは、濾し方もそろえると、違いの原因を判断しやすくなります。

液体の中の泡と、表面に浮く氷片は別のものです。氷片を取り除いてもシェイク由来の状態がすべて消えるわけではなく、濾過後にも微小な泡が観察されています。

シェイクとステアの違いは、ダブルストレインをしただけではなくなりませんでした。濾すことと、混ぜ方を変えることは、別々の調整として扱えます。

スイッチング酒を部分的に凍らせ、水分の多い氷を取り除いてから、果汁などを加える技法です。完成量を増やしすぎずに、酒へ別の風味を持たせることを目指します。

果汁の風味を加えつつ、少量にまとめたいカクテル / 果実の風味を取り入れたネグローニのアレンジ

作り方

  1. 酒を部分的に凍らせます。
  2. 水分の多い氷と、凍らずに残った液体を分けます。
  3. 残った液体に、果汁などを加えます。
  4. 仕込んだ酒の味に合わせて、カクテルの配合を調整します。
  • 果汁をそのまま足すと量が増えすぎる場合に、検討する価値があります。
  • 酒を部分的に凍らせられる冷却設備と、分離・計量のための道具が必要です。

部分凍結では、氷と凍らずに残る液体の組成が異なります。その差を利用して分け、残った液体へ別の素材を加えます。最終的な味は、分離と追加の両方で変わるため、仕込み後の酒を新しい材料として配合します。

Switched Jungle Birdでは、ラムをスイッチングで加工する際に、パイナップルとライムの清澄液（濁りを取り除いた液体）を使っています。 講演の趣旨では、食品での凍結の常識をそのまま移すのではなく、液体とカクテルの可能性を探る考えを示しています。凍結を保存以外の、風味を作る手段として見る姿勢です。

果実の風味を濃くしたいとき、果汁を増やすと総量も増え、酒の存在感が変わります。スイッチングは、先に酒から水分の多い部分を取り除き、そこへ別の液体を組み込む発想です。香味のある酒を仕込んでから、一杯を組み立てます。

この方法が面白いのは、サワーに果汁を増やす以外の道が開けることです。少量で仕上げたいトロピカルカクテルや、酒を中心にしたネグローニのアレンジでも、果実の風味を取り入れる余地が生まれます。

まず「完成量を増やさず、何の風味を加えたいか」を決めます。答えが明確な一杯ほど、スイッチングを採用する理由も明確になります。

凍結濃縮凍結を利用して水分の多い部分を分け、味の濃い部分を取り出す方法です。果汁などを加熱せずに濃縮したいときに使います。

少量の果汁で、しっかり風味を出したいとき / 加熱を避けて果汁を濃縮したいとき

作り方

  1. 凍結を利用し、水分の多い部分と濃い部分を分けます。
  2. 取り出した濃い部分の甘味、酸味、香りを確認します。
  3. 濃縮後の味に合わせて、カクテルの配合を調整します。
  • 果実の風味を強めることが目的なら、果汁を濃縮するだけで十分な場合もあります。

水分の多い部分を分けることで、残る部分の濃度を変えます。加熱濃縮とは工程が異なり、加熱を避けたい素材で検討できます。スイッチングとの違いは、濃縮後に別の液体を加えることが必須ではない点です。

既存の凍結濃縮をカクテルに応用し、Cosmosではクランベリーの濃縮とスイッチングを組み合わせています。複数の技法に、それぞれ役割を持たせた例です。

濃縮した果汁は、元の果汁の代わりに同量で使うより、少ない量から合わせる方が味を決めやすくなります。酸味や甘味も強く感じられるため、シロップや柑橘の量を一緒に調整します。

スローイング二つの容器の間で液体を注ぎ移し、空気に触れさせながら混ぜる方法です。氷はストレーナーで押さえ、片方の容器に残します。

ネグローニやブールヴァルディエの口当たりを変えたいとき / マンハッタンなどを、ステアとは異なる方法で仕上げたいとき

作り方

  1. 二つの容器と、氷を押さえるストレーナーを用意します。
  2. 氷を押さえながら、もう一方の容器へ液体を注ぎます。
  3. 液体を戻し、安定した流れで注ぎ移す動作を繰り返します。
  4. 温度と薄まり方を確認し、グラスに注ぎます。
  • 最初は高さを出すことよりも、こぼさず一定の流れで注ぐことを優先します。
  • ステアしたものと飲み比べ、口当たりの違いがそのカクテルに合うかを確認します。

注ぎ移すことで液体が空気に接する機会を作り、氷との接触で冷却と加水を進めます。高く注いだ距離だけでは完成状態を管理できないため、流れの安定と最終的な温度・濃さをそろえることが重要です。

動作の美しさも魅力ですが、まずは同じ配合でステアしたものと比べます。香りの感じ方、口当たり、温度を確認し、そのカクテルにとって得たい変化があるかで採用を決めます。

マティーニやマンハッタン / 毎回の仕上がりをそろえたい定番カクテル

作り方

  1. 目盛りに合わせて材料を量ります。
  2. 材料をこぼさず容器に移し、氷を加えます。
  3. バースプーンで、氷と液体を滑らかに動かします。
  4. 温度と薄まり方を確認し、グラスに注ぎます。
  • 材料の量に加え、氷の状態と仕上がりもそろえます。
  • 器具を替えたときは、同じ秒数で同じ仕上がりになるか確認します。

加水はアルコール度数だけでなく、甘味、酸味、苦味の感じ方にも関わります。Arnoldらの試飲では、すべてに共通する理想の加水率は得られませんでした。完成する温度で味を決めることが、実務上の大切な点です。
